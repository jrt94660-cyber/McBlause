# McBlause

Paper boss plugin: configurable arena, hourly respawn, 100 HP, abilities, boss bar, damage leaderboard, rewards.

Requirements: Paper/Purpur 1.21.11+, Java 21.

Commands: `/boss` status; `/boss arena` teleport; `/boss spawn` force spawn; `/boss kill` remove boss; `/boss info`; `/boss setarena`; `/boss reload`.
Permissions: `boss.use` (default true), `boss.admin` (default OP).

Configs: `config.yml`, `boss.yml`, `rewards.yml`, `messages.yml`, `arena.yml`, `damage.yml`.
